The predictor consumes program/configuration/data, never observed RTL cycle/event schedules. The RTL and model independently generate requests; they deliberately share the native external controller and Ramulator. This establishes compute timing conditional on that memory contract, not independent correctness of the memory/controller implementation or a production shell.
